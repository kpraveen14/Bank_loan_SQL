# 🏦 Bank Loan SQL Analysis

## 📌 Project Overview

This project focuses on analyzing bank loan data using SQL. The objective is to explore loan applications, loan status, applicant information, and other key business metrics using SQL queries.

## 🎯 Objectives

- Analyze loan application data
- Identify approved and rejected loans
- Calculate important loan-related metrics
- Analyze applicant information
- Practice SQL queries for data analysis
- Generate meaningful business insights

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- Git & GitHub
